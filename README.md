## Bullethost 介绍

Bullethost 这家公司，说起来还挺有意思的。

2017年成立，真正开始做生意是2018年底——那时候他们就租了几台服务器,想着试试水。结果一年不到,客户信任度上来了,他们直接买了自己的硬件设备,分别放在荷兰和保加利亚的数据中心。到2019年,业务范围又扩了,专用服务器、定制方案都搞起来了。

现在呢？他们所有硬件设备都是自己的——这可不是随便说说的,是实打实100%自有。设备用的是惠普企业级(HPE)和戴尔的服务器,放在欧洲的专业数据中心里。

他们主要提供这几种服务:

- **虚拟专用服务器 (VPS)**：KVM虚拟化技术,资源独享不共享
- **虚拟主机**：LiteSpeed网络服务器 + DirectAdmin控制面板
- **专用服务器**：裸机服务器,性能拉满
- **分销主机**：VPS分销和虚拟主机分销两种选择

特色功能也不少——支持加密货币支付(比特币、莱特币都行),提供免费DDoS防护,还有免费网站迁移服务。对了,他们还接受那种"不太方便说的业务",日志每周自动清理,匿名性做得挺到位。

客服支持是24/7全天候的,通常2小时内就能回复。说实话,这个响应速度在小型主机商里算是相当不错了。
